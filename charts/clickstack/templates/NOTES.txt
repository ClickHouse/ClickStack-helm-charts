ClickStack has been installed.

By default, this chart deploys the full ClickStack platform: HyperDX, ClickHouse
(via the ClickHouse Operator), MongoDB (via the MongoDB Community Operator), and
the OpenTelemetry Collector. Each component can be disabled to use an external
instance instead.

To disable a built-in component, set its enabled flag to false:
  helm upgrade {{ .Release.Name }} <chart-name-or-path> \
    --set clickhouse.enabled=false \
    --set mongodb.enabled=false \
    --set otel-collector.enabled=false

When disabling a component, override the corresponding endpoints in clickstack.config
to point at your external service (e.g. CLICKHOUSE_ENDPOINT, MONGO_URI).

Application Access:
  For security, the service uses ClusterIP and is not exposed externally by default.
  Choose one of the following access methods:
  
  1. Enable Ingress (Recommended for Production):
     Configure clickstack.ingress with your annotations and spec.
     See the chart documentation for nginx and ALB examples.
  
  2. Port Forward (Development/Testing):
     kubectl port-forward svc/{{ include "clickstack.hyperdx.fullname" . }} {{ .Values.clickstack.ports.app }}:{{ .Values.clickstack.ports.app }}
     Then access: http://localhost:{{ .Values.clickstack.ports.app }}
  
  Note: This application handles sensitive telemetry data and should not be exposed
  directly to the internet without proper authentication and encryption.

{{- if and (default (dict) .Values.clickstack.dashboards).enabled (ne (include "clickstack.hyperdx.dashboardsRbacCreate" .) "true") }}

WARNING: clickstack.dashboards.rbac.create is false. The dashboard watcher needs
read access (list/get/watch) to ConfigMaps in its discovery scope. Grant it
out-of-band (e.g. a Role/RoleBinding bound to the HyperDX ServiceAccount)
before installing: without it the watcher fails its startup sync and
crash-loops, leaving the whole pod NotReady. If access is revoked after
startup instead, the watcher stays Running but logs 403 errors and stops
picking up dashboard changes.
{{- end }}
